# Cashback Optimization Project 💳

This project is developed as part of the **Design and Analysis of Algorithms** course. It addresses the optimization problem of maximizing cashback rewards when using multiple credit cards across different spending categories.

## 📌 Project Overview
The goal is to distribute a given monthly budget across categories and cards to maximize total cashback while respecting the spending caps for each card.

## 🧩 Algorithms Used
1. **Backtracking Algorithm** (`CashBackBacktracking.java`): Explores possible allocations to find precise solutions under constraints.
2. **Greedy Algorithm** (`GreedyAlgorithm.java`): Makes locally optimal choices to quickly achieve high cashback returns.

## 📋 Inputs & Outputs
* **Inputs**: Monthly budget, credit cards with cashback schemes and spending caps, and spending categories.
* **Outputs**: Optimal card selection per category and total cashback earned.
